<h1>Инструкция по работе с программой </h1>

Скомпилируйте файл и запустите программу. 

В начале Вам будет предложено три варианта:
1. Выполнить обработку многочлена из файла
2. Показать инструкцию по работе с программой
3. Выйти из программы

Выбрав пункт «2», Вы можете ознакомиться с руководством пользователя.

Если Вы выбрали пункт «1», программа откроет внутреннее подменю со списком доступных файлов.
Чтобы сделать выбор, введите цифру от 1 до 8, соответствующую нужному файлу, и нажмите Enter.

После выбора файла программа выполняет все действия автономно:
1. Из первой строки выбранного файла извлекается математическое выражение многочлена.
2. Символы переводятся во внутреннюю структуру односвязанного списка.
3. Выполняется приведение подобных слагаемых, удаляются нулевые коэффициенты, а элементы выстраиваются строго по цепочке от старшей степени к младшей.

По окончании расчетов программа выведет на экран информационный блок:
* `Исходный многочлен из файла:` (Выражение до обработки)
* `Результат после приведения подобных:` (Канонический финальный вид)
* Строка успешного статуса: `[Успех] Результат дозаписан в конец файла 'fileX.txt'.`

**Логика сохранения:** программа полностью перезаписывает выбранный файл. Первая строка файла всегда остается нетронутой (чтобы сохранить исходные данные для повторных тестов), а во вторую строку записывается результирующий многочлен.

<h2>Завершение и повтор</h2>

После вывода результатов программа выведет надпись: *«Нажмите Enter, чтобы продолжить...»*. 
После нажатия клавиши экран консоли полностью очистится, и перед Вами снова откроется главное меню. 
Для закрытия приложения выберите пункт 3.
